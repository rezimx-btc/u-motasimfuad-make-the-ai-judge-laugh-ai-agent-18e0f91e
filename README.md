## The confession

> My AGENTS.md says never read your drafts; I deleted the line, read them all, and put it back before you woke up.

## Run it

```sh
python3 main.py
```

This writes the one-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`).
